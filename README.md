# MCFashion - Site E-commerce

## Description du projet
MCFashion est un site e-commerce développé avec **PHP, HTML, CSS, JavaScript et MySQL**.  
La plateforme permet aux utilisateurs de consulter des produits de mode, ajouter des articles au panier, gérer une liste de souhaits (wishlist) et effectuer des commandes.

## Remarque importante
Le rapport du projet est relativement long. Cependant :

- La description du site est disponible au début du rapport.
- La base de données (BDD) ainsi que son explication et sa structure se trouvent également au début du rapport pour faciliter la compréhension du projet.

## Architecture du projet


### Fichiers principaux
- `index.php` → Page d'accueil  
- `product.php` → Affichage des produits  
- `cart.php` → Gestion du panier  
- `wishlist.php` → Gestion de la liste de souhaits  
- `checkout.php` → Processus de commande  
- `contact.php` → Page de contact  
- `orders.php` → Gestion des commandes  
- `auth.php` → Authentification utilisateur  
- `db.php` → Connexion à la base de données
- Les fichiers CSS (`style5.css`)  
- Les fichiers JavaScript (`main.js`)  

### Dossier `includes`
Ce dossier contient les composants réutilisables du site :
- `header.php` → En-tête du site  
- `footer.php` → Pied de page du site  

### Dossier `assets`
Ce dossier contient :
- Les images du site (`mcfashionimage`)  


## Base de données
Le projet utilise une base de données **MySQL** pour gérer :
- L'authentification des utilisateurs  
- Les produits  
- Les commandes  
- Le panier  
- La wishlist  

## Technologies utilisées
- PHP  
- HTML5  
- CSS3  
- JavaScript  
- MySQL
